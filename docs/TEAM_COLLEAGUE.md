# Подключить коллегу (Дубай / intl)

Каждый маклер со своим Telegram ID получает отдельный кабинет. Чтобы второй человек видел те же заявки, владелец кабинета приглашает коллегу из **Настройки → Подключить коллегу**.

## Что нужно

- Always-on хост с `MULTI_USER=true` и `TELEGRAM_ALLOWED_USER_IDS=*` (см. `docs/DAILY_PILOT.md`).
- Оба открывают Mini App того же бота (валидный Telegram `initData`).
- Числовой Telegram ID коллеги (например через @userinfobot).

## Владелец кабинета

1. Настройки → **Подключить коллегу**.
2. Ввести Telegram ID коллеги.
3. Выбрать роль: **Смотреть** (`viewer`) или **Смотреть и отвечать** (`editor`).
4. Нажать **Создать доступ** — появится одноразовый токен. Передать коллеге ID владельца (свой Telegram ID) и токен вне чата с клиентами.
5. Лимит: до 5 коллег на кабинет. **Отозвать** сразу закрывает доступ.

Токен в базе хранится только как hash (`HASH_SALT`). После принятия или отзыва старый токен недействителен.

## Коллега

1. Открыть Mini App бота (свой аккаунт).
2. Настройки → блок **Принять приглашение**.
3. Ввести Owner ID (Telegram ID владельца) и токен.
4. В инбоксе выбрать workspace владельца в переключателе **Мои / …**.

`viewer` видит заявки, карточки и просмотры, но не отправляет ответы и не стирает данные.  
`editor` может править черновик, отправлять, бронировать и архивировать. Каналы (Telegram Business / WhatsApp) остаются у владельца.

## API (для отладки)

- `GET /v1/intl/team`
- `POST /v1/intl/team/invite` `{ "telegram_id": "777", "role": "viewer" }`
- `POST /v1/intl/team/accept` `{ "owner_id": "42", "token": "…" }`
- `POST /v1/intl/team/revoke` `{ "telegram_id": "777" }`
- Список заявок: `GET /v1/intl/leads?workspace=<owner_telegram_id>`
